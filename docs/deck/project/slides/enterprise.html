Built to be operated, not only demonstrated

Tenant isolation

Every record belongs to an organisation. A request for another organisation’s record returns 404.

Roles and keys

Viewer, analyst and admin. API keys are stored as hashes and can be revoked.

Tamper-evident audit

A hash chain per organisation, checked on demand.

Provenance

Each result records the pipeline version, models, settings and the document’s SHA-256.

Observability

Rate limits, health probes, Prometheus metrics and request IDs in every log line.

Free-tier deployment

GitHub Pages, Cloud Run and MongoDB Atlas, with a runbook.

Design and risks: docs/ARCHITECTURE.md, docs/THREAT_MODEL.md, docs/RUNBOOK.md

Each card maps to code and tests in the repository. The threat model lists what each control does not cover. The cloud deployment files are written and checked locally, but have not yet been run against a real Cloud Run project; that is stated on the last slides.
