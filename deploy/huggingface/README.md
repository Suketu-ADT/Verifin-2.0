# VERIFIN 2.0 API

Backend of VERIFIN 2.0, a verifier for LLM-written summaries of financial reports. Source, documentation and the web
interface: https://github.com/Suketu-ADT/Verifin-2.0

This Space only serves the API. Its secrets (database connection string, signing key) are set in the Space settings, not in
this repository.
