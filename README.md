# VERIFIN

**"Interpretable Hallucination Detection for Financial LLMs"**

VERIFIN is an advanced web application designed for evidence-grounded verification of LLM-generated financial summaries and answers. Built as a sophisticated AI/ML prototype, it provides a professional, highly readable interface for identifying and analyzing AI hallucinations in the financial sector.

## 🚀 Overview

VERIFIN verifies whether statements generated by an LLM (from financial documents like Annual Reports, 10-Ks, or Earnings Reports) are actually supported by the source document. It breaks down the text into atomic factual claims, retrieves relevant evidence, and classifies each claim using a Natural Language Inference (NLI) model.

**The Verification Pipeline:**
LLM OUTPUT ➔ CLAIM DECOMPOSITION ➔ EVIDENCE RETRIEVAL ➔ NLI CLASSIFICATION ➔ RISK ANALYSIS ➔ EXPLAINABLE OUTPUT

## ✨ Features

- **Document Processing**: Upload financial PDFs and documents, which are automatically chunked and stored for page-aware retrieval.
- **Evidence Retrieval**: Leverages vector embeddings to find relevant source evidence for each claim.
- **NLI Classification**: Classifies every claim as `SUPPORTED`, `CONTRADICTED`, or `UNVERIFIABLE`.
- **Risk Analysis**: Calculates overall verification scores, claim confidence, and flags high-risk hallucinations.
- **Explainable Interface**: A highly intuitive, modern frontend providing full visibility into the AI's decision-making process.

## 🛠️ Technology Stack

**Frontend**
- React 19 + TypeScript
- Vite
- Tailwind CSS v4 & Framer Motion
- Recharts (for risk and confidence data visualization)
- Lucide React (Icons)

**Backend / AI Architecture**
- Python + FastAPI
- PyMuPDF (Document processing)
- Sentence Transformers (Retrieval)
- NLI Models (e.g., DeBERTa-v3)

## 💻 Getting Started

### Frontend Development

The frontend is built with Vite and uses modern React features.

```bash
# Navigate to the frontend directory
cd frontend

# Install dependencies
npm install

# Start the development server
npm run dev
```

The application will be available at `http://localhost:5173`.

### Environment Setup

Rename `.env.example` to `.env` in the `frontend` directory and populate any necessary API endpoints or feature flags.

## 🎨 Design Philosophy

VERIFIN is designed to look like a modern AI fintech product:
- **Trustworthy & Professional**: Deep navy, neutral grays, and clean typography.
- **Clear Risk Indicators**: Green (Supported), Red (Contradicted), and Amber (Unverifiable).
- **Intuitive Visualizations**: Easy-to-understand charts and badges for technical ML data.
